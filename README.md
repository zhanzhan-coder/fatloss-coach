# 减脂教练 🔥

拍照记录饮食 + AI 健身教练 + 运动打卡 + 体重里程碑的网页应用（PWA）。
可以添加到手机主屏幕，用起来和 App 一样。

## 功能

- 📷 **拍照记饮食**：拍一下饭菜，AI 自动识别食物、估算热量和三大营养素，可手动修正
- 🍚 **每日仪表盘**：根据你的身体数据自动算热量预算，实时显示还能吃多少
- 🏃 **运动板块**：记录运动（按 MET 公式估算消耗）、记步数、本周有氧/力量完成度
- ⚖️ **体重里程碑**：内置你的减脂计划曲线（148→110斤），体重曲线 vs 计划虚线一目了然
- 🧑‍🏫 **AI 教练**：知道你的全部数据和计划，可以点评当天表现、随时问答
- ☁️ **云端同步**：数据存在服务器上，换手机、换浏览器都不丢

## 快速开始

### 1. 安装 Node.js（18 或更高版本）

去 https://nodejs.org 下载安装即可。

### 2. 获取免费的 AI Key

1. 打开 https://open.bigmodel.cn 注册（手机号即可）
2. 进入「API Keys」页面，创建一个 Key
3. 用到的模型 `glm-4v-flash`（看图）和 `glm-4-flash`（对话）都是**免费**的

### 3. 配置并启动

```bash
cd ~/Desktop/硅基大脑1号
cp .env.example .env   # 首次需要；用文本编辑器打开 .env 填上 Key
npm install            # 首次需要
npm start              # 以后每次开机想用时，只需要这一条
```

### 4. 手机使用

**同一 WiFi 下**：手机浏览器访问 `http://你电脑的局域网IP:3000`
（Mac 查看 IP：系统设置 → WiFi → 详细信息，或在终端运行 `ipconfig getifaddr en0`）

**添加到主屏幕**（变成"App"）：
- iPhone：Safari 打开 → 分享按钮 →「添加到主屏幕」
- 安卓：Chrome 打开 → 右上角菜单 →「添加到主屏幕」

### 5. 部署到公网（随时随地能用，可选）

本地跑需要电脑开着且在同一 WiFi。想随时随地用，可以部署到免费云平台：

- **Zeabur / Render / Railway**：注册后连接 GitHub 仓库一键部署（本项目是标准 Node 应用，启动命令 `npm start`）
- 或者自己买台便宜的云服务器，`node server.js` 挂后台即可
- **部署到公网前务必在 .env 里设置 `APP_PASSWORD`**，否则别人扫到地址就能看到你的数据

数据保存在服务器的 `data.json` 文件里，备份它就备份了全部数据。

## 使用建议

- 每周称重2~3次（如周四+周末早上），空腹、排便后、同一台秤；看周趋势别看单日波动
- 每餐开吃前拍照，养成习惯只要 3 秒
- 每天睡前点一下「今日点评」，让教练帮你复盘
